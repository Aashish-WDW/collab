# GoLookAround — Brochure

A one-page brochure site for GoLookAround: curated experiences, retreats and events.

Built with TanStack Start, React, Tailwind CSS and shadcn/ui.

## Development

You need Node.js and npm (or bun).

```sh
npm i
npm run dev
```

Other scripts:

```sh
npm run build   # production build
npm test        # run tests
```

## Where things live

- `src/content/content.ts` — all copy, contact details and image paths
- `src/components/brochure/` — the page sections
- `src/components/ui/` — shared UI (hero tunnel, polaroid gallery, gradient footer)
- `public/images/` — photography
