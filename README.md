# PageFlow Navigation

Read the file and build the application. Use dummy images for now. I'll give the original images later. Only the frontend. In the mobile layout, at the bottom, make three floating buttons. - The left button will be the previous page.

- The right button will be the next page.

- The middle button will be a label. It will not be a button, just a label.

All three should be in pill format and should show the page title.
